# Контракт первой версии
Python 3.9+, только стандартная библиотека в runtime: tkinter, sqlite3, zipfile (XLSX). Windows portable PyInstaller onedir. UI Russian. No web/server.
Ownership: data agent storage.py; business agent service.py; UI agent ui.py; root __main__.py, paths.py, xlsx.py, packaging; QA tests/* docs/* README.md after slot available. Do not edit others' files; report requested changes.
All records dicts. Cartridge: id (str primary identity, immutable), name, printers, status, operation_date ISO YYYY-MM-DD. Multiple instances same name allowed; name describes model, no uniqueness or implicit shared editing.
Profile: organization, full_name.
History: id (integer), cartridge_id, action, old_status (nullable), new_status, operation_date, recorded_at (timezone ISO), organization, full_name, reason, details (JSON str optional).
Storage(path): .path Path, .connection sqlite3; .transaction() context manager BEGIN IMMEDIATE commit/rollback; .get_cartridge(id)->dict|None; .list_cartridges()->list[dict]; .insert_cartridge(record); .update_cartridge(id, fields); .get_profile()->dict; .save_profile(organization, full_name); .add_history(record); .list_history(cartridge_id=None)->list[dict]; .backup(destination)->Path; .restore(source)->Path (returns pre-restore safety backup); .close(). Write methods DO NOT commit within transaction. Initialization committed. backup uses SQLite backup API; restore validates schema/integrity first, safety copy, safe replacement; rejects own DB destination.
Service(storage): .storage; .get(id)->dict (unknown raises ValidationError); .list(query='', status='', sort_by='id', descending=False); .add(id,name,printers='',operation_date=None)->dict; .edit(id,name,printers='')->dict; .operate(id, action, operation_date, reason='', confirmed=False)->dict; .profile()->dict; .save_profile(organization,full_name); .history(id=None); .backup(path); .restore(path). ValidationError(ValueError) Russian messages. action keys 'send','receive','write_off'. confirmed required only write_off; false raises ValidationError without mutation. All writes transactional with snapshot profile history. Creation default today Ready; edit prohibited written off, logged with today (or max today/previous op date), no backwards date. Status values exact 'Готов','На заправке','Списан','Утерян'. Dates input ISO only; UI shows hint ГГГГ-ММ-ДД. Explicit duplicate validation and sqlite uniqueness. Do not coerce numeric IDs silently. Pure centralized TRANSITIONS. Preserve leading zeroes; strip outer whitespace.
UI: App(root, service), builds screens. root supplied tkinter.Tk; module no main side effects. Navigation main four buttons + star profile. Warehouse search, filter, sortable table, plus and edit modal, history view, export and backup/restore controls (profile OK). UI catches exceptions with Russian dialogs. Operations lookup preview before confirmation, mandatory reason writeoff, no stale preview commit after changed ID. xlsx.export_inventory(records, destination)->Path available from root. UI minimum 900x600 with resizing/scrollbars.
