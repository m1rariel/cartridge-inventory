# Перенос складских экземпляров из Excel

На странице «Склад» кнопка «Импорт XLSX» принимает выгрузку склада текущей и предыдущей версии приложения. Перед записью показывается число и пример импортируемых строк; без подтверждения база не меняется.

Книга должна содержать таблицу с заголовками `ID`, `Наименование картриджа`, `Подходящие принтеры`, `Статус`, `Дата` и одну строку на физический экземпляр. Допускаются заголовки в строке 1 или после информационных строк экспорта приложения. Формат `.xls` не поддерживается.

| Столбец | Тип | Обязательность | Пример |
|---|---|---|---|
| ID | Текст | Обязателен, уникален | `0001` |
| Наименование картриджа | Текст | Обязательно | `HP 12A` |
| Подходящие принтеры | Текст | Необязательно | `HP LaserJet 1010; 1020` |
| Статус | Текст: `Готов`, `На заправке`, `Списан`, `Утерян` | Обязательно | `Готов` |
| Дата | Текст `ГГГГ-ММ-ДД` | Обязательно | `2026-10-28` |

ID и дата должны быть сохранены в Excel как текст. Если ячейка ID числовая, программа откажет в импорте, поскольку ведущие нули нельзя надёжно восстановить. Один ID соответствует одному экземпляру, совпадение названия модели не означает дубликат.

Импорт дополняет склад и не обновляет и не удаляет существующие записи. Если ID уже есть в базе (включая удалённые со склада) или повторяется в файле, весь импорт отклоняется. Неверная строка, статус или дата также отклоняют весь файл. Успешная загрузка атомарна: сбой записи откатывает склад, журнал и пополнение справочников вместе.

Экспорт со страницы «Склад» выгружает все активные экземпляры, независимо от фильтра и поиска, и включает эти пять колонок. Организация и ответственный над таблицей носят справочный характер: импорт не меняет профиль. Старый журнал операций из XLSX не переносится; для каждой загруженной записи создаётся событие «Импорт из Excel» с текущим профилем и исходным статусом/датой. XLSX не заменяет резервную копию базы.

Если обновляете приложение на том же компьютере, предпочтительно заменить EXE и открыть его с прежним каталогом данных: штатная миграция SQLite сохраняет профиль, склад и полный журнал операций. Excel-перенос предназначен для загрузки выгрузки, когда миграция исходной базы недоступна. Перед любым переносом сделайте резервную копию.

## Импорт справочников моделей и принтеров

Импорт справочников доступен в настройках и принимает JSON либо Excel `.xlsx`. Файл `.xls` не поддерживается. Самый простой шаблон Excel — лист `Справочники` с первой строкой заголовков:

| Картриджи | Принтеры |
|---|---|
| HP 12A | HP LaserJet 1010 |
| Canon 725 | Canon LBP 6000 |

Списки независимы: пустые ячейки допустимы. Также можно импортировать листы `Картриджи` и `Принтеры` (значения в первом столбце) или складской XLSX со столбцами `Наименование картриджа` и `Подходящие принтеры`. Список принтеров в одной ячейке разделяйте точкой с запятой, запятой или новой строкой.

Импорт объединяет значения со справочниками приложения, убирает повторы без учёта регистра и не удаляет уже имеющиеся позиции. Он не импортирует и не изменяет складские экземпляры.
