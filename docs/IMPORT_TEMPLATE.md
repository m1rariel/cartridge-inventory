# Предлагаемый шаблон импорта (импорт пока не реализован)

Книга XLSX, лист `Склад`, первая строка — заголовки, далее одна строка на физический экземпляр. Без объединённых ячеек, формул, макросов и промежуточных заголовков.

| Столбец | Тип | Обязательность | Пример |
|---|---|---|---|
| ID | Текст | Обязателен, уникален | `0001` |
| Наименование картриджа | Текст | Обязательно | `HP 12A` |
| Подходящие принтеры | Текст | Необязательно | `HP LaserJet 1010; 1020` |
| Статус | Текст из утверждённого списка | Требует согласования | `Готов` |
| Дата | Текст `ГГГГ-ММ-ДД` | Требует согласования | `2026-10-28` |

ID должен быть текстом ещё в исходном файле: потерянные Excel ведущие нули нельзя достоверно восстановить автоматически. Один ID соответствует одному экземпляру, совпадение названия не означает дубликат.

До реализации нужны обезличенный реальный файл и решения: что делать с повторным ID внутри книги и в базе, можно ли обновлять поля, означает ли пустая ячейка очистку, переносить ли начальные статусы и даты, что делать со списанными/утерянными экземплярами, отклонять ли весь файл при одной ошибке. Предложение для безопасного старта — предпросмотр и полное отклонение импорта при ошибке, без удаления отсутствующих в файле записей. Это предложение, не реализованное поведение.

Экспорт текущей версии имеет эти пять столбцов, а над таблицей печатает организацию и ФИО из профиля. Он не обещает обратный импорт и не заменяет резервную копию: журнал в XLSX не включён.
